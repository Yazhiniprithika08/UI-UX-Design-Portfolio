## ✨ Features

- 💎 **Modern UI Design:** Clean, elegant aesthetics leveraging glassmorphism, tailored color palettes, and micro-interactions.
- 📱 **Responsive Layout:** Fluid layouts engineered for desktop, tablet, and mobile breakpoints.
- ⚡ **Interactive Components:** Dynamic design components, animated state transitions, and interactive visual elements.

- 📲 **Mobile-Friendly Design:** Touch-optimized interactions and mobile-first layout strategy.

## 🎯 Design Process

My design methodology follows a structured, iterative human-centered approach to solve complex problems and deliver impactful digital experiences:

```
  🔬 Research  ──►  👤 Personas  ──►  ✏️ Wireframes  ──►  🎨 Prototype  ──►  🧪 Testing  ──►  🚀 Final Design
```

<br />

> [!TIP]
> ### 1️⃣ 🔬 Research & Empathize
> Understanding user needs, pain points, market trends, and business goals through surveys, competitive analysis, and user interviews.

> [!TIP]
> ### 2️⃣ 👤 Personas & Mapping
> Synthesizing user insights into actionable user personas, empathy maps, user journeys, and information architecture trees.

> [!TIP]
> ### 3️⃣ ✏️ Wireframes & Ideation
> Exploring concepts with low-fidelity sketches and paper wireframes to map layout structures and core interaction loops rapidly.

> [!TIP]
> ### 4️⃣ 🎨 High-Fidelity Prototyping
> Crafting pixel-perfect UI designs, interactive prototypes, micro-animations, and reusable design components in Figma.

> [!TIP]
> ### 5️⃣ 🧪 Usability Testing & Iteration
> Conducting qualitative usability testing sessions with real users, analyzing feedback metrics, and refining UI interactions.

> [!TIP]
> ### 6️⃣ 🚀 Final Design & Handoff
> Finalizing production-ready UI assets, documenting design tokens, and collaborating on technical implementation.

## 🚀 Getting Started

Follow these simple steps to run this portfolio locally on your machine:

### Prerequisites
- A modern web browser (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge)
- [Git](https://git-scm.com/) installed on your machine

### Installation Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Yazhiniprithika08/UI-UX-Design-Portfolio.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd UI-UX-Design-Portfolio
   ```

3. **Open the project in your browser:**
   - Double-click on `index.html`, or
   - Right-click `index.html` and choose **Open with Browser**, or
   - Use the **Live Server** extension in VS Code.
